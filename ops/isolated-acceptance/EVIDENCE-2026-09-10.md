## Re-run after Cursor review fixes — same day

All three Bugbot findings were confirmed real and fixed:

1. (High) The standalone OnFailure check reported `notify_prereq` for a live
   deploy unit lacking `OnFailure=`, which is a blocked category — so the
   apply that would install the line refused to run. Exactly the production
   state; bootstrap would have deadlocked. The standalone check is removed:
   mapping content equality already guarantees the line (spec 5.1), and the
   acceptance now pre-installs an OnFailure-less deploy unit before apply to
   prove convergence.
2. (High) `deploy.sh` called `owed-restarts` / `clear-restarts` without the
   required `--repo`, with stderr hidden — restart debts would never run or
   clear. Fixed; the offline deploy harness stub now rejects any sync call
   missing `--repo`.
3. (Medium) Rollback flags were set only after success, so a failed
   daemon-reload/Vector-restart skipped the recovery sequence and never
   recorded the debt. Flags now flip before the action; both debts persist
   for the next tick.

Fresh-container result after fixes: **ALL-ISOLATED-ACCEPTANCE-PASSED**
(25/25, now including the production-state bootstrap regression). Unit
tests: 39 passed, ruff clean.
